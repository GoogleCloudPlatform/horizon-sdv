Horizon module

openbsw-module

A module-owned openbsw namespace. OpenBSW workflow pods schedule onto the OpenBSW node pool.

Workflows

openbsw-bsw-builder builds OpenBSW unit tests, POSIX and NXP S32K148 targets, runs AI review (Antigravity SDK) on failure and stores artifacts in GCS. openbsw-builder-image builds the openbsw-builder image.

Namespace

Enabling the module on the main environment creates openbsw. WorkflowTemplates stay in the platform workflows namespace.

Node pool

Workflow pods and the CAN DaemonSet select sdv-openbsw-build-node-pool (workloadLabel: openbsw) and tolerate workloadType=openbsw. The pool labels stay with Terraform. Existing Jenkins jobs keep their own scheduling.

CAN kernel

DaemonSet openbsw-can-kernel loads can, can-raw, and vcan. It runs as openbsw-can-kernel with no API token and no Role. The Jenkins CAN DaemonSet is left in place.
