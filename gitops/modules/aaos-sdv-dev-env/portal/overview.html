AAOS SDV Development Environment Module Standalone

This module provides automated build and validation pipelines for creating the AAOS SDV Development Environment.

The Dockerfile and all image assets are cloned at run time from the public aaos-sdv-demos repository; nothing is vendored in this repository.

Pipeline: aaos-sdv-dev-env-init

Fast preflight, run this first. Verifies that aaos-sdv-demos is reachable and that the configured revision exists. Fails in seconds instead of after a multi-gigabyte build.

Pipeline: aaos-sdv-dev-env-execute

Automates end-to-end artifact creation and validation:

  • Step 1: Container Build — Clones aaos-sdv-demos and builds the ASfP + CARLA 0.9.15 + SOME/IP image via the shared common-docker-image-build template, pushing to Artifact Registry as aaos-sdv-dev-env.
  • Step 2: Workspace & Candidate Snapshot — Provisions a high-CPU builder workstation, installs CARLA 0.9.15, applies patches and builds AAOS 26Q2, then captures a candidate GCE persistent disk snapshot.
  • Step 3: Automated Test Suite — Launches a GPU-accelerated test workstation from the candidate snapshot and runs a BATS acceptance suite on it, covering CARLA RPC (port 2000) and dual-VM vehicle simulation (launch_2vm plus cvd fleet).
  • Step 4: Atomic Promotion — On test success, labels the validated snapshot is-latest=true and publishes a ready-to-use aaos-sdv-dev-env-latest workstation configuration built from it.

How to Run

Submit from the Argo Workflows UI, the Developer Portal, or via CLI:

horizon workflow submit --module aaos-sdv-dev-env --template aaos-sdv-dev-env-init

horizon workflow submit --module aaos-sdv-dev-env --template aaos-sdv-dev-env-execute
