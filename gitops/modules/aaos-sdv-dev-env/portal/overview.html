aaos-sdv-dev-env

AAOS 26Q2 (Android 16) CARLA 0.9.15 COVESA vSOME/IP Antigravity IDE 2.24 Android Studio for Platform NVIDIA T4 WebRTC Desktop

Browser-accessible, GPU-accelerated Cloud Workstations environment for building, simulating, and debugging Software-Defined Vehicle (SDV) applications across Android Automotive OS (AAOS), SOME/IP vehicle services, and the CARLA 3D autonomous driving simulator.

What Is Inside the Workstation

  • WebRTC Desktop (Selkies + Openbox): Low-latency HTML5 desktop streamed over port 80 with hardware NVIDIA T4 NVENC video encoding and Vulkan/OpenGL rendering.
  • Dual-VM Cuttlefish Vehicle Stack (launch_2vm): Orchestrated by cvd, booting VM 1 (AAOS 26Q2 IVI + Cluster display + VHAL) alongside VM 2 (DebOS Linux running COVESA vsomeip, vhal_someip_bridge, and carla_someip_bridge).
  • CARLA 0.9.15 3D Simulator: Unreal Engine 4 driving simulator listening on RPC port 2000 and feeding live vehicle telemetry into AAOS CarPropertyManager.
  • AI-Assisted IDEs: Pre-installed Google Antigravity IDE (2.24.0) and Android Studio for Platform (ASfP) with the AOSP and SDV demo sources pre-populated in /home/user.

Cloud Workstation Configurations

Workstations run on n1-standard-32 (32 vCPUs, 120 GB RAM, nested virtualization) with 1x nvidia-tesla-t4 GPU and a 1000 GB pd-ssd persistent /home disk:

  • aaos-sdv-dev-env-euw3 & aaos-sdv-dev-env-latest (europe-west3): Pre-populated from the latest verified AAOS 26Q2 + CARLA snapshot.
  • aaos-sdv-dev-env-usw4 (us-west4): Secondary regional configuration backed by the same verified snapshot across multi-zone T4 capacity.
  • aaos-sdv-dev-env-clean & aaos-sdv-dev-env-clean-usw4: Clean 1000 GB pd-ssd configs for fresh workspace builds.
Always-On Workshop Readiness Automatic idle and running timeouts are set to 0s (disabled) so pre-started attendee workstations remain running throughout the event.

Argo Workflow Templates

  • aaos-sdv-dev-env-init: Fast preflight check that verifies Git connectivity to google/aaos-sdv-demos and confirms the configured commit/branch exists.
  • aaos-sdv-dev-env-execute: End-to-end build, test, and promotion pipeline:
    1. Build Container Image (or reuse existing image via skipImageBuild=true).
    2. Publish Clean Configs in europe-west3 and us-west4.
    3. Build or Import Disk Snapshot (build-snapshot or existingSnapshotName).
    4. Automated BATS Verification: Boots an ephemeral GPU test workstation and validates CARLA RPC port 2000 plus launch_2vm Cuttlefish fleet health.
    5. Atomic Promotion: Labels the verified snapshot is-latest=true,env=production and updates regional workstation configs.

Developer Quick Start

Once connected to a running workstation via the Cloud Workstations browser URL:

  • Launch Dual-VM AAOS + SOME/IP Bridge: Open a terminal and run launch_2vm (or inspect status with cvd fleet) and open the Cuttlefish WebRTC display at https://localhost:8443.
  • Start CARLA 0.9.15: Launch CARLA from the desktop menu or terminal to stream live driving physics and vehicle signals over SOME/IP into AAOS.
  • Edit & Deploy Code: Launch Antigravity or ASfP from the application menu to modify VHAL properties, SOME/IP bridges, or AAOS system apps.
