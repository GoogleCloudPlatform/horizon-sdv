Horizon module

abfs-service-module

ABFS 0.1.14 GKE data plane: dedicated server and uploader node pools, server, Gerrit uploaders, pusher-config bootstrap, and CASFS on the uploader nodes. License Secret, Spanner/GCS and the uploader manifest table stay in abfs-data; this module consumes them when licensed is on. Builds run on the pool of abfs-client-ubuntu.

What this module deploys

  • Node pools abfs-data-server-node-pool and abfs-data-uploader-node-pool (license GCE metadata on both pools; git-pusher has the same entitlement check as the server)
  • abfs-server and abfs-gerrit-uploader
  • Pusher-config Job, CASFS installer, PDBs / NetworkPolicies / VPAs (license-gated)

Depends on abfs-data

Requires abfs-data first: Secret horizon/abfs-license, runtime SA abfs-license@…, Spanner, and GCS. Import the license there before enabling this module.

Enable order abfs-data → import license → abfs-service-module
License gate PreSync validator fails sync if Secret horizon/abfs-license is missing or empty.
