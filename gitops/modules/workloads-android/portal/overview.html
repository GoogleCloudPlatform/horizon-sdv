Horizon module

workloads-android

Brings the Android / AAOS pipeline stack into the shared workflows namespace: curated GitOps, the AAOS builder Helm release, reusable docker-image workflow templates, and Cuttlefish instance template workflows (x86_64 and ARM64).

Argo CD sources

The child Application merges four sources on one destination namespace:

  • gitops/workloads/android — umbrella values and wiring
  • workloads/android/pipelines/builds/aaos_builder/helm — builder pipelines
  • workloads/android/pipelines/environment/docker_image_template/helm — image build templates
  • workloads/android/pipelines/environment/cf_instance_template/helm — Cuttlefish GCE instance templates (x86 and ARM64)

Prerequisite

Requires workloads-common so ClusterWorkflowTemplates, GitHub-app credential prep, and shared workflow RBAC exist before Android charts sync.

Injected from MODULE_CONFIG Project, region, zone, domain, and Android repo URL or branch come from the root config.
