Version 0.1.0 Cloud Workstations Partner: The Qt Company

About This Module

Provides self-service Google Cloud Workstations with Squish, the GUI test automation tool from The Qt Company, preinstalled on the Horizon GNOME desktop. The workstation cluster, configuration, image repository and IAM are provisioned declaratively with Config Connector when the module is enabled.

Prerequisites

  • A Squish license key (request a free trial from The Qt Group on the Squish product page), stored in Secret Manager as squish-license-key: 
    printf '%s' "$SQUISH_LICENSE_KEY" | \
  gcloud secrets create squish-license-key --data-file=-
  • The horizon-gnome base image, published by the Jenkins job Cloud Workstations > Workstation Images > Horizon GNOME.

Getting Started

  1. Run squish-workstation-init to build and push the Squish image.
  2. Optionally run squish-workstation-execute to smoke-test a workstation.
  3. Open the Cloud Workstations page in the Google Cloud console, create a workstation from the Squish configuration, start it and launch it in the browser.

Capabilities

  • Squish preinstalled: under /opt/qt/squish, linked as ~/squish, licensed automatically at startup.
  • Persistent home: 500 GB pd-balanced disk per workstation (retained on deletion).
  • Fast start: one pre-started e2-standard-8 VM kept in the pool by default.
