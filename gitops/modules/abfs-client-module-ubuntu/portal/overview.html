Horizon module

abfs-client-ubuntu

Ubuntu based ABFS(Android Build File System) build node pool. Jenkins and Argo Workflows both schedule ABFS-backed Android builds on this Ubuntu GKE node pool if enabled.

Node pool created

One KCC ContainerNodePool, abfs-build-node-pool-ubuntu: c2d-highcpu-112, 500 GB disk, UBUNTU_CONTAINERD, autoscaling 0–20 nodes from zero.

Why the Ubuntu variant

This image does not ship casfs, so the kernel module is built per node. The pool fixes Secure Boot off (immutable after creation) so that module can load.

Enable and disable

Hard dependencies workloads-android and abfs-service-module are enforced. Jenkins agents and Argo Workflow pods land here via taint / nodeSelector android-abfs-build.
