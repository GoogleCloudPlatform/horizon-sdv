# Phase 2: Automated Terraform Configuration

This guide details how the agent automatically prepares `terraform/env/terraform.tfvars` from minimal user inputs (`GCP_PROJECT_ID` and `ROOT_DOMAIN`).

---

## 1. Minimal Questionnaire

The agent prompts the user only for:
1. **`sdv_gcp_project_id`**: Target Google Cloud Project ID.
2. **`sdv_root_domain`**: Target root domain (e.g. `example.com`).

---

## 2. Automated Parameter Derivation

The agent automatically populates all other configuration parameters using sensible and secure defaults:

| Variable | Derivation / Value | Note |
| :--- | :--- | :--- |
| `sdv_gcp_backend_bucket` | `"<GCP_PROJECT_ID>-horizon-tfstate"` | Auto-created in GCS with versioning |
| `sdv_gcp_compute_sa_email` | `<PROJECT_NUMBER>-compute@developer.gserviceaccount.com` | Auto-queried via `gcloud` |
| `sdv_gcp_region` | `"europe-west1"` | Default recommended region |
| `sdv_gcp_zone` | `"europe-west1-d"` | Default recommended zone |
| `sdv_env_name` | `"dev"` | Default subdomain / environment name |
| `scm_type` | `"github"` | Auto-detected |
| `scm_auth_method` | `"none"` | Public repo mode by default |
| `scm_repo_url` | `git config --get remote.origin.url` | Auto-detected from local clone |
| `scm_repo_branch` | `"main"` | Default branch |
| `sdv_keycloak_admin_password` | Auto-generated random string | 16 chars (uppercase, lowercase, number, symbol) |
| `sdv_keycloak_horizon_admin_password` | Auto-generated random string | 16 chars (uppercase, lowercase, number, symbol) |
| `sdv_enable_network_policies` | `true` | Standard security enabled |
| `sdv_dns_dnssec_enabled` | `true` | Standard DNSSEC enabled |
| `sdv_enable_kms_encryption` | `false` | Standard secrets (avoids undeletable KMS keyrings) |

> [!IMPORTANT]
> **Credential Display Policy**:
> During deployment handoff, **only the two locally-generated Keycloak admin passwords** (`horizon-admin` and `admin`) are presented to the user.
> Service passwords generated by Terraform inside Cloud Build (Argo CD, Jenkins, Gerrit, Grafana, PostgreSQL, MCP Gateway) are synced directly to workloads via Kubernetes External Secrets and are **not** displayed proactively. They can be queried on-demand from Secret Manager if ever required for emergency/break-glass access:

```bash
# Emergency on-demand fallback password retrieval:
# Argo CD Admin (admin)
gcloud secrets versions access latest --secret="argocd-admin-password-b64" --project=<GCP_PROJECT_ID> | base64 --decode && echo

# Jenkins Admin (admin)
gcloud secrets versions access latest --secret="jenkins-admin-password-b64" --project=<GCP_PROJECT_ID> | base64 --decode && echo

# Gerrit Admin (admin)
gcloud secrets versions access latest --secret="gerrit-admin-password-b64" --project=<GCP_PROJECT_ID> | base64 --decode && echo

# Grafana Admin (admin)
gcloud secrets versions access latest --secret="grafana-admin-password-b64" --project=<GCP_PROJECT_ID> | base64 --decode && echo

# PostgreSQL Password
gcloud secrets versions access latest --secret="postgres-admin-password-b64" --project=<GCP_PROJECT_ID> | base64 --decode && echo
```

## 4. Sample Generated `terraform.tfvars` (Password-Free)

```hcl
# GCP Configuration
sdv_gcp_project_id       = "my-cloud-project-123"
sdv_gcp_region           = "europe-west1"
sdv_gcp_zone             = "europe-west1-d"
sdv_gcp_compute_sa_email = "9876543210-compute@developer.gserviceaccount.com"
sdv_gcp_backend_bucket   = "my-cloud-project-123-horizon-tfstate"

# Environment Metadata
sdv_env_name    = "dev"
sdv_root_domain = "your-domain.com"

# SCM Configuration
scm_type        = "github"
scm_auth_method = "none"
scm_repo_url    = "https://github.com/GoogleCloudPlatform/horizon-sdv"
scm_repo_branch = "main"

# Feature Flags
sdv_enable_network_policies   = true
sdv_dns_dnssec_enabled       = true
sdv_enable_kms_encryption     = false
enable_arm64_dedicated_subnet = false
```
